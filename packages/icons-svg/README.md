# @bxshefby/icons-svg

Bitrix24 UI icons (collection `bx24`) as optimized SVG files: `svg/<set>/<name>.svg`,
e.g. `@bxshefby/icons-svg/svg/outline/check-l.svg`.

Monochrome icons use `currentColor`: inline them to inherit the text color (in `<img>` they render black).
For frameworks prefer [`@bxshefby/icons-json`](https://www.npmjs.com/package/@bxshefby/icons-json).

Catalog: https://b24-icons.bx-shef.by · Docs: https://github.com/bx-shef/b24-icons
